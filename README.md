# IMU_WristAngle

双 IMU 手腕相对姿态测量实验项目。

## 项目目标

使用两个 WT-IMU63 模块分别安装在前臂端和手部端，通过串口读取 IMU 数据，在 MATLAB 中实时计算手部相对于前臂的姿态角，并进行可视化显示。

## 当前进展

目前已经完成：

- WT-IMU63 串口通信协议解析
- 加速度、角速度、欧拉角、四元数数据读取
- 双 IMU 实时姿态显示
- 基于模块内置四元数的相对姿态计算
- 基于原始角速度的 Gyro Integration
- 自适应 Mahony / MH 姿态解算初步实现
- 双 IMU 相对欧拉角和轴角实时显示

## 主要结论

初步实验发现：

- 模块内置四元数在低速运动下表现较好，但快速动态运动下存在滞后和 yaw 漂移。
- 直接使用角速度积分的 GI 方法动态响应更快，但长时间存在积分漂移。
- 自适应 Mahony 方法在低动态阶段加入加速度计修正后，可以在一定程度上降低长期漂移。
